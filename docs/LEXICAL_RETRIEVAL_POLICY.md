# Angela 无向量词法检索政策

当前阶段不建设向量数据库，也不使用向量相似度决定试验召回。正式检索继续使用结构化 SQLite 数据库。

## 固定链路

1. 年龄、性别、疾病、城市、地区、时间、分期和患者条件相互独立提取。
2. 用户原始疾病词始终保留；疾病规范化失败不得清空其他字段。
3. 只有 `disease_concepts.json` 中已审计的规范词、同义词和相关词可以自动扩展。
4. Mini 模型可以判断路由和提取明确字段，但未审计的模型规范名称不能自动成为查询词。
5. SQLite 在适应症、公开标题、专业标题、药物和入排标准中执行词法匹配。
6. 每个返回结果必须带有数据库字段命中证据，再经过招募状态、时间、地区、年龄、性别和健康受试者冲突守卫。
7. 原词没有结果时直接说明没有找到；不自动扩大到父级疾病。后续可以提示用户确认建议词，但未经确认不执行扩展查询。

## 可审计性

内部结果记录 `retrieval_policy=lexical_evidence_only_no_vector` 及实际查询词。模型输出不能覆盖这些证据，也不能把 UNKNOWN 改写成符合。

新增疾病表达通过失败查询日志进入待审计清单，确认后再补充到词库，而不是在线自动学习并立即影响正式结果。
