# Code of Conduct

Be respectful, constructive, and specific. Harassment, discrimination, threats, disclosure of private information, and unsafe handling of medical or security-sensitive data are not acceptable.

Project discussions should focus on reproducible technical behavior and use fictional or public examples. Maintainers may edit or remove content, close discussions, or restrict participation when conduct threatens people, privacy, security, or the project's purpose.

Report conduct concerns privately through the repository owner's GitHub profile or an appropriate private GitHub channel.
