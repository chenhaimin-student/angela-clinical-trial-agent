# Security Policy

## Reporting a vulnerability

Use GitHub's private security advisory feature for this repository. Do not open a public issue containing a secret, patient information, private endpoint, exploit details, or production configuration.

Include the affected path, impact, reproduction steps using synthetic data, and a suggested mitigation when possible. Do not test systems or data you do not own or have permission to assess.

Only the latest public commit is supported. Production databases, Hermes credentials, browser profiles, private messaging-platform configurations, and operational environments are outside this repository and must never be attached to a report.

If a real credential is found, revoke or rotate it before discussing remediation. Never paste the credential value into an issue.
