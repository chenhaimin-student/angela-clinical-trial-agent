# Contributing

This repository is maintained as a personal technical portfolio. Focused bug fixes, tests, documentation improvements, and privacy hardening are welcome.

1. Create a branch from `main`.
2. Use only public or clearly fictional data in code and tests.
3. Run the relevant test groups described in `docs/TESTING.md`.
4. Run a secret scan before opening a pull request.
5. Explain behavior changes and security implications in the pull request template.

Do not submit production databases, raw archived pages, logs, screenshots, browser profiles, patient information, credentials, internal addresses, or third-party code without clear redistribution rights.

By contributing, you agree that your contribution may be distributed under the repository's Portfolio Source-Available License 1.0 and that you have the right to provide it.
